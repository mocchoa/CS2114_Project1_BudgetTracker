#Penny Pet
Penny Pet is a simple budgeting application that helps users track income and expenses, organize transactions by category, and receive budgeting feedback based on the 50/30/20 budgeting rule.
#Features
Add income and expense transactions
Support one-time and recurring transactions
Track monthly balance
Organize spending by category
Provide budgeting feedback
Handle invalid user input
Carry recurring transactions into a new month
#How to Run
Clone or download this repository.
Open the project in Eclipse.
Make sure Java 17 is installed.
Open `PennyPetApp.java`.
Run `PennyPetApp.java` as a Java Application.
#Testing
JUnit tests are included in the project.
To run the tests in Eclipse:
Open a test class.
Right-click the file.
Select `Run As -> JUnit Test`.
